# CPvPHelper

Клиентский мод для Crystal PvP под **Minecraft 26.2 (Fabric)**. Настраивается через Mod Menu.

Готовый jar: [`dist/cpvphelper-1.0.0.jar`](dist/cpvphelper-1.0.0.jar). Он собран до StunSlam, SpearSwap и TriggerBot, для них собери мод сам (см. «Сборка»).

## Установка

- Minecraft 26.2, Fabric Loader 0.19.5+, Java 25
- [Fabric API](https://modrinth.com/mod/fabric-api) для 26.2
- [Mod Menu](https://modrinth.com/mod/modmenu) 20.x (нужен только для экрана настроек)

## AutoTotem

Как только вторая рука пустеет, кладёт туда тотем.

- **Тотем в хотбаре**: мод выбирает слот с тотемом, делает ванильную смену рук (как клавиша F) и возвращает прежний слот. В инвентаре ничего не кликается, останавливаться не нужно.
- **Тотем только в инвентаре**: мод на 1 тик отпускает клавиши движения, как это делает открытие инвентаря. Потом кликает тотем во вторую руку (как F над слотом) и закрывает инвентарь. Скорость игрока мод не трогает. На земле ты тормозишь за счёт обычного трения, а в воздухе летишь дальше по инерции и не зависаешь.

Настройки: вкл/выкл, свап из хотбара, свап из инвентаря, свап из инвентаря в воздухе, длительность остановки (1–3 тика), задержка и случайная задержка, замена других предметов во второй руке.

## AnchorPlace

Держишь меч и жмёшь ПКМ по блоку. Мод ставит якорь возрождения, заряжает его светокамнем, возвращается на слот меча и взрывает.

- Якорь и светокамень должны лежать в хотбаре.
- Каждый шаг — обычный ванильный ПКМ по тому, на что смотрит прицел. В воздух якорь не ставится, только на реальный блок.
- По умолчанию один шаг за тик: поставить, зарядить, взорвать (около 100 мс). Задержки настраиваются от 0 до 5 тиков.
- В Незере не срабатывает: там якорь ставит точку возрождения, а не взрывается.

Настройки: вкл/выкл, только на земле, задержка зарядки, задержка взрыва, взрывать или только ставить с зарядкой.

## StunSlam

Бьёшь существо топором (ЛКМ). Сразу после удара топором мод выбирает булаву в хотбаре, бьёт ей ту же цель и возвращается на топор. Топор сносит щит, удар булавой приходит следом.

- Булава должна лежать в хотбаре. Если булав несколько, первой берётся булава с «Плотностью».
- Удар булавой — обычный ванильный ЛКМ по цели под прицелом: выбрать слот булавы, ударить, выбрать слот топора.
- По умолчанию срабатывает только в падении, когда удар булавой будет сокрушающим (падение больше 1,5 блока, не на элитрах).
- Задержка между топором и булавой настраивается от 0 до 5 тиков. 0 — в тот же тик.

Настройки: вкл/выкл, только в падении, только по щиту, задержка булавы.

## SpearSwap

Attribute swap с копьём по своей клавише «Спир-свап» (любая клавиша или кнопка мыши). В один тик мод выбирает копьё в хотбаре, делает укол (ЛКМ копьём) и возвращается на предмет, который был в руке.

- Работает с любым предметом в руке. Копьё должно лежать в хотбаре. Первым берётся копьё с самым высоким уровнем «Выпада».
- С «Выпадом» каждый укол толкает тебя вперёд. Зажми клавишу, и уколы идут каждый раз, когда атака заряжена.
- Проверки как у обычного ЛКМ: атака заряжена, руки свободны, ты ничего не используешь.
- Сам «Выпад» работает по ванильным правилам: не в воде, не на элитрах, не верхом, еды больше 6 (в креативе не важно).

Настройки: вкл/выкл, повтор при удержании, задержка повтора (0–10 тиков).

## TriggerBot

Бьёт существо под прицелом, как только удар готов. Проверка идёт на каждом кадре, а не на каждом тике: прицел двигается каждый кадр, поэтому удар уходит в тот же кадр, когда прицел наводится на цель. Задержка до 50 мс между тиками пропадает.

- Удар — обычный ванильный ЛКМ по цели под прицелом со всеми проверками клика: заряд атаки, дальность оружия, свободные руки. Цель за блоком не бьётся. Цель берётся по той позиции, которую знает сервер.
- Удар топором с включённым StunSlam тоже работает: булава бьёт следом.
- **Криты.** Если ты в прыжке и удар уже готов, бот ждёт падения, чтобы удар стал критом. Если сервер видит твой спринт, бот бьёт сразу: удар со спринтом не бывает критом.
- **W-tap и s-tap.** После удара со спринтом сервер снимает спринт, а клиент об этом не сообщает, пока ты не отпустишь W или не нажмёшь S. Бот следит за спринтом на стороне сервера. Если ты делаешь w-tap или s-tap, готовый удар ждёт, пока спринт снова дойдёт до сервера, и отбрасывает как удар со спринтом.
- **Случайные тайминги.** Каждый удар берёт свою задержку реакции между минимумом и максимумом (значения ближе к середине выпадают чаще) и свой порог заряда атаки.
- Не бьёт, пока открыт экран, ты ешь, ставишь щит, ломаешь блок, работает AnchorPlace или ждёт удар булавы StunSlam.

Настройки: вкл/выкл (по умолчанию выключен), только игроки, только с оружием, заряд атаки (50–100%), мин. и макс. реакция (0–250 мс), ожидание крита и ожидание спринта (0–10 тиков, 0 — не ждать).
 и клавиша «Спир-свап» назначаются в «Управление → CPvPHelper». По умолчанию они не заданы.

## Сборка

Нужен JDK 25:

```
./gradlew build
```

jar появится в `build/libs/`.
