# CPvPHelper

Клиентский мод для Crystal PvP под **Minecraft 26.2 (Fabric)**. Настройки открываются и закрываются комбинацией **Ctrl+Shift+X**.

Готовый jar: [`dist/cpvphelper-1.0.0.jar`](dist/cpvphelper-1.0.0.jar). Он собран до StunSlam, SpearSwap, TriggerBot, SprintReset, JumpReset и AutoCart, для них собери мод сам (см. «Сборка»).

## Установка

- Minecraft 26.2, Fabric Loader 0.19.5+, Java 25
- [Fabric API](https://modrinth.com/mod/fabric-api) для 26.2

## AutoTotem

Как только вторая рука пустеет, кладёт туда тотем.

- **Тотем в хотбаре**: мод выбирает слот с тотемом, делает ванильную смену рук (как клавиша F) и возвращает прежний слот. В инвентаре ничего не кликается, останавливаться не нужно.
- **Тотем только в инвентаре**: мод на 1 тик отпускает клавиши движения, как это делает открытие инвентаря. Потом кликает тотем во вторую руку (как F над слотом) и закрывает инвентарь. Скорость игрока мод не трогает. На земле ты тормозишь за счёт обычного трения, а в воздухе летишь дальше по инерции и не зависаешь.

Настройки: вкл/выкл, свап из хотбара, свап из инвентаря, свап из инвентаря в воздухе, длительность остановки (1–3 тика), задержка и случайная задержка, замена других предметов во второй руке.

## AnchorPlace

Держишь меч и жмёшь ПКМ по блоку. Мод ставит якорь возрождения, заряжает его светокамнем, возвращается на слот меча и взрывает.

- Якорь и светокамень должны лежать в хотбаре.
- Каждый шаг — обычный ванильный ПКМ по тому, на что смотрит прицел. В воздух якорь не ставится, только на реальный блок.
- По умолчанию один шаг за тик: поставить, зарядить, взорвать (около 100 мс). Задержки настраиваются от 0 до 5 тиков.
- В Незере не срабатывает: там якорь ставит точку возрождения, а не взрывается.

Настройки: вкл/выкл, только на земле, задержка зарядки, задержка взрыва, взрывать или только ставить с зарядкой.

## StunSlam

Бьёшь существо топором (ЛКМ). Сразу после удара топором мод выбирает булаву в хотбаре, бьёт ей ту же цель и возвращается на топор. Топор сносит щит, удар булавой приходит следом.

- Булава должна лежать в хотбаре. Если булав несколько, первой берётся булава с «Плотностью».
- Удар булавой — обычный ванильный ЛКМ по цели под прицелом: выбрать слот булавы, ударить, выбрать слот топора.
- По умолчанию срабатывает только в падении, когда удар булавой будет сокрушающим (падение больше 1,5 блока, не на элитрах).
- Задержка между топором и булавой настраивается от 0 до 5 тиков. 0 — в тот же тик.

Настройки: вкл/выкл, только в падении, только по щиту, задержка булавы.

## SpearSwap

Attribute swap с копьём по своей клавише (выбирается в «Биндах», любая клавиша или кнопка мыши). В один тик мод выбирает копьё в хотбаре, делает укол (ЛКМ копьём) и возвращается на предмет, который был в руке.

- Работает с любым предметом в руке. Копьё должно лежать в хотбаре. Первым берётся копьё с самым высоким уровнем «Выпада».
- С «Выпадом» каждый укол толкает тебя вперёд. Зажми клавишу, и уколы идут каждый раз, когда атака заряжена.
- Проверки как у обычного ЛКМ: атака заряжена, руки свободны, ты ничего не используешь.
- Сам «Выпад» работает по ванильным правилам: не в воде, не на элитрах, не верхом, еды больше 6 (в креативе не важно).

Настройки: вкл/выкл, повтор при удержании, задержка повтора (0–10 тиков).

## TriggerBot

Бьёт существо под прицелом, как только удар готов. Проверка идёт на каждом кадре, а не на каждом тике: прицел двигается каждый кадр, поэтому удар уходит в тот же кадр, когда прицел наводится на цель.

- Удар — обычный ванильный ЛКМ по цели под прицелом со всеми проверками клика: заряд атаки, дальность оружия, свободные руки. Цель за блоком не бьётся.
- **Дистанция.** Бот бьёт только цели не дальше заданной дистанции (от глаз до точки удара). Больше ванильной дальности она не бывает.
- Удар топором с включённым StunSlam тоже работает: булава бьёт следом.
- **Криты.** Если ты в прыжке и удар уже готов, бот ждёт падения, чтобы удар стал критом. Если сервер видит твой спринт, бот бьёт сразу: удар со спринтом не бывает критом.
- **W-tap и s-tap.** После удара со спринтом сервер снимает спринт, пока ты не сделаешь w-tap или s-tap. Во время тапа готовый удар ждёт, пока спринт снова дойдёт до сервера.
- **Случайные тайминги.** Каждый удар берёт свою задержку реакции между минимумом и максимумом и свой порог заряда атаки.
- Не бьёт, пока открыт экран, ты ешь, ставишь щит, ломаешь блок, работает AnchorPlace, AutoCart или ждёт удар булавы StunSlam.

Настройки: вкл/выкл (по умолчанию выключен), только игроки, только с оружием, макс. дистанция (1,50–3,00 блока), заряд атаки (50–100%), мин. и макс. реакция (0–250 мс), ожидание крита и ожидание спринта (0–10 тиков, 0 — не ждать).

## SprintReset

Сброс спринта после удара со спринтом по существу. Мод работает только клавишами движения, как человек: при w-tap на 1–3 тика отпускает W, при s-tap вместо этого нажимает S. Клиент перестаёт бежать, потом снова бежит с W, и следующий удар снова идёт со спринтом.

- Спринт возвращается сам только с зажатой клавишей спринта или с toggle sprint. С двойным нажатием W он не вернётся.
- Удары по кристаллам и другим не-существам тап не запускают.

Настройки: вкл/выкл (по умолчанию выключен), s-tap вместо w-tap, задержка (0–3 тика), длительность (1–3 тика).

## JumpReset

Когда удар отталкивает тебя, пока ты стоишь на земле, мод нажимает прыжок в том же тике, когда применяется отдача от сервера. Пакет скорости обрабатывается до тика игрока, поэтому прыжок уходит вместе с движением этого же тика.

- Срабатывает только на земле, не в воде и лаве, не верхом и при закрытом экране.

Настройки: вкл/выкл (по умолчанию выключен), шанс (0–100%), при использовании предметов.

## AutoCart

Пока летит твоя стрела, мод считает, куда она упадёт, ставит туда рельсу и вагонетку с ТНТ и поджигает её огнивом. После этого снова выбирается слот, который был в руке.

- Рельсы (или энергорельсы), вагонетка с ТНТ и огниво должны лежать в хотбаре. Работает со стрелами и спектральными стрелами, трезубцы не считаются.
- Каждый шаг — обычный ванильный ПКМ предметом из хотбара. Рельса ставится только на твёрдый верх блока и не дальше ванильной дальности по блокам. Поджечь вагонетку можно в пределах досягаемости по существам (3 блока).
- Если вагонетка ещё не появилась (пинг), поджог ждёт её до 1 секунды.
- **Выстрел из лука** по отдельному бинду: мод берёт лук из хотбара, натягивает его заданное число тиков, стреляет и возвращается на прежний слот.
- Стрелы, которые уже летали до включения функции, не учитываются.

Настройки: вкл/выкл (по умолчанию выключен), энергорельсы, поджигать, пополнять вагонетки из инвентаря, дистанция (1,00–4,50 блока), задержка шагов (0–5 тиков), натяжение лука (3–20 тиков).

## Бинды

Экран «Бинды» открывается кнопкой в начале настроек (Ctrl+Shift+X). Нажми на бинд, потом любую клавишу или кнопку мыши. Backspace или Delete убирает бинд.

- У TriggerBot, SprintReset, JumpReset и AutoCart есть режим **Toggle** (по умолчанию): нажатие включает и выключает функцию, на экране видно состояние. В режиме **Hold** включённая функция работает только пока клавиша зажата.
- Без бинда функция работает всегда, когда включена.
- Отдельные клавиши есть у спир-свапа и у выстрела из лука AutoCart.
- В «Управлении» мод ничего не добавляет.

## Сборка

Нужен JDK 25:

```
./gradlew build
```

jar появится в `build/libs/`.
